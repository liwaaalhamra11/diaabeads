# Diaa's Beads logo

`diaas-beads-logo.pdf` is the original logo (white on black). The web files in
`public/images/` were made from it:

| File | Use |
|---|---|
| `logo.png` | Black artwork on transparent — white backgrounds (landing page, admin, PDF reports) |
| `logo-small.png` (256px) | Small copy used in PDF reports |
| `favicon.png` (512px) | Browser tab icon — original black square |
| `apple-touch-icon.png` (180px) | Phone home-screen icon |
